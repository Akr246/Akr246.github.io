# ARYA — THE SERIES

Cinematic portfolio for Arya K. Ravi. Live: https://akr246.github.io/series/

## Run locally

Requires Node.js 20+.

```sh
npm ci
npm run dev
```

Open the displayed development URL with `/series/` appended.

## Update and publish

Edit `src/data/portfolio.ts`; replace documents in `public/assets/` as required. Run `npm run build`, then copy the contents of `dist/` to the repository’s `series/` directory and commit both source and build. GitHub Pages publishes from the existing main branch.
